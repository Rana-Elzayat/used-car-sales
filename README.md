# used-car-sales Analysis project
# 🚗 Used Car Price Prediction & Business Analytics

An end-to-end data analytics and machine learning project for predicting used car prices and analyzing sales data through interactive dashboards.

# 📌 Project Overview

This project combines Data Analysis, Business Intelligence, and Machine Learning to help users estimate used car prices and gain insights into vehicle sales data.

The project consists of four main stages:

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Power BI Dashboard
- Machine Learning Model
- Deployment using Gradio

---

# ❗ Problem Statement

Pricing used cars is challenging because vehicle value depends on many factors such as manufacturer, age, mileage, engine power, transmission, fuel type, and location.

Traditional pricing methods are often subjective and inconsistent, leading to inaccurate prices for buyers and sellers.

This project uses machine learning to predict a fair market price based on historical vehicle data while providing business insights through interactive Power BI dashboards.



# 🎯 Objectives

- Clean and preprocess raw vehicle data.
- Explore relationships between vehicle features.
- Build interactive Power BI dashboards.
- Train and evaluate multiple regression models.
- Select the best-performing model.
- Deploy the model using Gradio for real-time predictions.



# 📊 Dataset

The dataset contains information about used vehicles, including:

- Manufacturer
- Location
- Vehicle Type
- Fuel Type
- Transmission
- Color
- Seats
- Doors
- Manufactured Year
- Mileage
- Engine Power
- Purchased Date

# 🤖 Machine Learning

Regression models were trained and compared to predict vehicle prices.

The best-performing model was selected based on evaluation metrics and retrained using the complete dataset before deployment.



# 🚀 Deployment

The final model was deployed using **Gradio**, allowing users to:

- Enter vehicle specifications
- Validate input values
- Predict vehicle price instantly
- View a summary of the entered vehicle
